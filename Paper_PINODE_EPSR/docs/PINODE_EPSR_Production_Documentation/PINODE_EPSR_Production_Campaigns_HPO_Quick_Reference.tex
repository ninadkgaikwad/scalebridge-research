\section*{Campaign lifecycle}
HPO TRAIN-only $\rightarrow$ freeze best HP $\rightarrow$ full TRAIN multi-start restarts $\rightarrow$ checkpoint gates $\rightarrow$ VALIDATION selects accepted restart $\rightarrow$ final TEST Sim1/Sim2/Sim3.

\section*{Controller override semantics}
\code{deadband_half_width_C=1.0} means $\pm1$ C around setpoint (2 C total band). Precedence: user override $>$ observed TRAIN data $>$ documented fallback. Kitchen heating remains explicitly extrapolative/OOD if unobserved in TRAIN even when user-overridden.

\section*{Important batch-size implementation note}
The search space includes batch\_size=64, but default HPO execution caps effective batch size at 32. A best trial may therefore record 64 while being evaluated with effective 32; final training may use 64 because its cap defaults to 64. Review before treating batch size as scientifically resolved.
