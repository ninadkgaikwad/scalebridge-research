RESUME SAFETY
D8.2 stores the exact runner configuration in each aggregation_manifest.json.
--resume only skips a completed aggregation output when its stored runner
configuration exactly matches the requested configuration. Changing selected
policies or any policy parameter causes the aggregation output to be rebuilt.
