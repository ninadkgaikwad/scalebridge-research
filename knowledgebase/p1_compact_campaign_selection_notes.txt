P1 Compact Campaign Selection Notes
===================================

Campaign ID
-----------
p1_ashrae2013_one_zone_compact_4b4c

Final selected compact building set
-----------------------------------
1. RestaurantFastFood
2. OfficeSmall
3. RetailStripmall
4. ApartmentMidRise

Rationale
---------
The full P1 EnergyPlus campaign includes 16 ASHRAE 90.1-2013 PNNL prototype
commercial buildings across 4 selected weather/climate locations. The compact
campaign is a first controlled campaign intended to cover a small but diverse
subset before launching the complete 64 building-weather campaign.

The final compact set gives the following progression:

    3 zones  -> RestaurantFastFood -> food service / high internal gains
    6 zones  -> OfficeSmall        -> simple office baseline
    10 zones -> RetailStripmall    -> retail / schedule and lighting diversity
    27 zones -> ApartmentMidRise   -> multifamily residential-like diversity

Data-root policy
----------------
The compact campaign runner does not write repo-root scratch folders.

The expected generated-data root is:

    C:\Users\ninad\Dropbox\NinadGaikwad_PhD\Gaikwad_Research\From_WSU_OneDrive\BuildingModelingProject_Condensed\Data\ScaleBridge

Use:

    $env:SCALEBRIDGE_GENERATED_DATA_ROOT = "C:\Users\ninad\Dropbox\NinadGaikwad_PhD\Gaikwad_Research\From_WSU_OneDrive\BuildingModelingProject_Condensed\Data\ScaleBridge"

Generated campaign data is written under:

    <SCALEBRIDGE_GENERATED_DATA_ROOT>\campaigns\p1_ashrae2013_one_zone_compact_4b4c\generation\cases\...

Normalized pre-opyplus IDFs are written under:

    <SCALEBRIDGE_GENERATED_DATA_ROOT>\campaigns\p1_ashrae2013_one_zone_compact_4b4c\normalization\idfs\<case_id>\normalized.idf

Original DOE/PNNL source IDFs are never modified.

Required source-code support
----------------------------
A reusable pre-opyplus IDF normalization module was added:

    src/scalebridge/integration/energyplus/idf/pre_opyplus_normalization.py

The compact runner uses it to normalize selected source IDFs into the ScaleBridge
data root before calling the variable-wise EnergyPlus generation pipeline.

Original DOE/PNNL IDFs are never modified.

Init-file note
--------------
No mandatory __init__.py update is required.

The runner imports the normalization module directly:

    from scalebridge.integration.energyplus.idf.pre_opyplus_normalization import (
        normalize_idf_before_opyplus,
    )

If desired later, the normalization function can be exported from
src/scalebridge/integration/energyplus/idf/__init__.py, but it is not required
for the compact runner.
