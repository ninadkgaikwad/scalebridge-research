ScaleBridge Phase E0
E0-6 Mathematics v2.4 Bibliography Recovery

Purpose
-------
Recover the shared thermal-modeling bibliography from the authoritative
pre-v2.2 backup, because the v2.2 PowerShell hotfix read the UTF-8 bibliography
without an explicit input encoding before writing UTF-8. Under Windows
PowerShell/code-page behavior this can apply an additional mojibake layer to
non-ASCII author names.

Recovery strategy
-----------------
1. Do NOT attempt to reverse the current multiply-corrupted bibliography.
2. Read the pre-v2.2 backup using Python UTF-8 strict decoding.
3. Normalize the three known non-ASCII author spellings to classic LaTeX-safe
   ASCII commands:
     Baydin2018AD       -> At{\i}l{\i}m G{\"u}ne{\c{s}} Baydin
     Paszke2019PyTorch  -> Andreas K{\"o}pf
     Harris2020NumPy    -> St{\'e}fan J. van der Walt
4. Re-apply the PyTorch matrix-exponential title correction:
     torch.linalg.matrix\_exp
5. Require the repaired shared bibliography to contain ASCII only.
6. Run a complete pdflatex -> bibtex -> pdflatex -> pdflatex build.

Scientific changes
------------------
NONE. No equations, RC semantics, backend contracts, parameter-estimation
coordinates, or implementation code are changed.
